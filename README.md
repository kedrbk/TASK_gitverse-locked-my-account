# **Инструкция по настройке Google-таблиц для совместной работы**

**НАЧАЛО РАБОТЫ:**
> 1. Войдите в Google-аккаунт и создайте (или используйте существующую) таблицу [https://drive.google.com].
> 2. В новой таблице будут предложены шаблоны, которые вы можете использовать в проекте. Далее таблицу можно будет видоизменить по своему усмотрению.

**НАСТРОЙКА РАБОЧЕЙ ОБЛАСТИ:**
Если таблицей будет пользоваться большое количество участников , целесообразно защитить ее от случайных правок там, где это не нужно. Для этого необходимо настроить рабочую область:
> 1. Нажмите правой кнопкой мыши на листе и выберите [Защитить лист].
> 2. В открывшемся окне отметьте [Исключить отдельные ячейки] и выберите диапазон, в котором предполагается редактирование ячеек (остальной лист будет защищен от правок).
> 3. Задайте разрешения на редактирование этого диапазона. Это может быть как обычное уведомление о нежелательных правках, так и полный запрет на изменение содержимого для всех, кроме вас и выбранных участников.

**СОВМЕСТНЫЙ ДОСТУП:**
> 1. Чтобы открыть файл перейдите сверху в [Настройки Доступа].
> 2. Добавьте участников по почте (от их Google-аккаунта) или откройте доступ и поделитель ссылкой.
